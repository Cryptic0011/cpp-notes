Machine Language = 

**Binary** or Bit

**Assembly** language is a human readable machine language.
ex. mov al, 0x61

The **operation**, what the instruction does is identified by a short abbr. move is to be understood for "move" which is an operation that copies bits from one location to another.

**Registers** are accessed by a name. al is the name of a specific register on the cpi

numbers are expressed in **hexidecimal** ex. 0x61.

The example assemble instruction  copies the hex number 0x61 into the al CPU register

Here is the same instruction as above in C/C++: `a = 97;`.

High level languages like c++ are compiled. A compiler translates c++ into machine code.
