### Void return values

functions are not required to return a value back to the caller. To tell the compiler that a function does not return a value, a return type of **void** is used.

```cpp
void printHi()
{
    std::cout << "Hi" << '\n';

    // This function does not return a value so no return statement is needed
}
```

In the above, the function has a use but a value does not have to be returned to the caller. As such, the function not does return a value and is called a **non-value returning function** or **void function**.

### Void functions do not need a return statement

A void function will automatically return to the caller at the end of the function. No return statement such as `return 0;` is required.

```cpp
void printHi()
{
    std::cout << "Hi" << '\n';

    return; // tell compiler to return to the caller -- this is redundant since the return will happen at the end of the function anyway!
} // function will return to caller here
```

---
### Void functions cant be used in expression that require a value

Some expressions require values. ex:

```cpp
std::cout << ;  // compile error: no value provided
```

above, cout needs a value to print

```cpp
// void means the function does not return a value to the caller
void printHi()
{
    std::cout << "Hi" << '\n';
}

int main()
{
    printHi(); // okay: function printHi() is called, no value is returned

    std::cout << printHi(); // compile error

    return 0;
}
```

The first call to printHi() is called in a context that does not require a value. In the second call, it will not compile since printHi has a void return type. meaning it does not return a value.

---

### Returning a value from a void function is a compile error

Trying to return a value from a non-value returning function will result in a compilation error.

```cpp
void printHi() // This function is non-value returning
{
    std::cout << "In printHi()" << '\n';

    return 5; // compile error: we're trying to return a value
}
```
