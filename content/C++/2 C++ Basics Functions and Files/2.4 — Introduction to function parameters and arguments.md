
### Function parameters and arguments

In many cases, it is useful to be able to pass information to a unction being called, so that the function has data to work with. EX if we wanted to write a functino to add two numbers, we need some way to tell the function which two numbers to add when we call it. Otherwise, how woiuld the function know what to add? We do that vi function parameters and arguments.

A **function parameter** is a variable used in the header of a function. Function parameters work almost identically to variables defined inside the function but with one difference: they are initialized with a value provided by the caller of the function.

Function parameters are defined in the function header by placing them in between the parentheses after the function name, with multiple parameters being separated by commas.

ex:

```cpp
// This function takes no params. It does not rely on the caller for anything.
void doPrint()
{
	std::cout << "In doPrint()\n"
}

// The function takes one integer parameter named x
// The caller will supply the value of x
void printValue(int x)
{
	std::cout << x << '\n';
}

// This functino has two integer params, x and y. 
// The caller will supply the value of both params
int add(int x, int y)
{
	return x + y;
}
```

An **argument** is a value that is passed from the caller to the function when a function call is made:

```cpp
doPrint(); // this call has no args
printValue(6); // 6 is the argument passed to the function 
add(2, 3); // 2 and 3 are the arguments pased to the function add() 
```

### How params and args work together

When a function is called, all of the parrams of the function are creates as variables, and the value of each of the args is copied into the matching param. This process is called **pass by value**. Function params that utilize pass by value called **value parameters**. ex:

```cpp
void printValues(int x, int y);
{
	std::cout << x << '\n';
	std::cout << y << '\n';
}

int main()
{
	printValues(6, 7); // This functino call has two args: 6 & 7
	return 0;
}
```
Terminal:
```
6
7
```

When function printValues is called with args 6 & 7, printValues parameter x is created and initialized with the value of 6. and printValues parameter y is created and initialized with the value of 7.

### How params and return vals work together

by using both params and a return value, we can create functions that take data as input, do some calculations with it, and return the value to the caller. EX:

```cpp
#include <iostream>

int add(int x, int y)
{
	return x + y;
}

int main()
{
	std::cout << add(4, 5) << '\n'; //args 4,5 are passed to the function add()
	return 0;
}
```
Terminal:
```
9
```

Execution starts at the top of main. when add(4,5) is evaluated, function add is called with parameter x being initialized with value 4, and parameter y being initialized with value 5.

The return statement in function add evaluates x+y to produce the val 9, which is then returned back to main. This value of 0 is then sent to std::cout to be printed on the console.

The first statement is staightforward. In the second statement, the arguments are expressions that get evaluated before being passed. In this case, 1 + 2 evaluates to 3, so 3 is copied to parameter x. 3 * 4 evaluates to 12, so 12 is copied to parameter y. add(3,12) resolves to 15.

next pair of statements is easy as well:
```cpp
int a{5};
std::cout add(a,a) << '\n'; //evaluates 5+5
```

In this case, add() is called where the value of a is copied into both parameters x and y. since a has value 5, add(a,a) = add(5,5), which resolves to value 10.

First tricky statement:
```cpp
std::cout << add(1, multiply(2,3)) << '\n'; //evaluates 1 + (2*3).
```

When the function add is executed, the program needs to determine what the values for parameters x and y are. x is simple since we just passed it the int 1. To get the value for param y, it needs to evaluate multiply(2,3) first. The program calls multiply and initializes z =2 and w= 3, so multiply(2,3) returns the integer value 6. That return value of 6 can now be used to initialize the y param of the add function. add(1,6) returns integer 7., which is then passed to std::cout for printing.

The following statement looks tricky bc because one of the arguments given to add is another call to add.

```cpp
std::cout << add(1, add(2,3)) << '\n'; // evaluates 1 + (2+3)
```

But this case works exactly the sa,e is the prior case. add(2,3) resolves first, resulting in the return value of 5. now i can resolve add(1,5) which evaluates to the value of 6, which is passed to cout to print.

### Unreferenced params and unnamed params.

in certain cases you will encounter functions that have parameters that are not used in the body of the function. These are called **unreferenced parameters**. ex:

```cpp
void doSomething(int count) // warning: unreferenced param count
{
	// This function used to do something with count but it is not used any longer.
}

int main()
{
	doSomething(4);
	
	return 0;
}
```

Just like with unused local variables your compiler will probably warn that variable `count` has been defined but not used

In a function definition, the name of a function parameter is optional. Therefore, in cases where a function parameter needs to exist but is not used in the body of the function, you can simply omit the name. A param  without a name is called an **unnamed parameter**.

```cpp
void doSomething(int) // ok: unnamed param will not generate warning
{
}
```

The Google C++ style guide recommends using a comment to document what the unnamed param was:

```cpp
void doSomething(int /*count*/)
{
}
```

Why would we not name a func?
we have a function with a single param. later, the func is updated in some way, and the value of the param is no longer needed. If the now-unused func param were simply removed, then every existing call to the function would break. This would require us to find every call to the function and remove the unneeded argument. This might be a lot of work. It also might not even be possible. Instead we leave the param as is and just have it do nothing.

Example output:

Use:

12 months per year
365 days per year

- `ageInMonths()` should return the calculated months.
    
- `ageInDays()` should return the calculated days.
    
- `printAge()` should print the results.
