A **function** is a reusable sequence of statements designed to do a certain job.

main() is an example of a function, but as the code gets longer and longer, you cant put everything into main(). Functions that you write yourself are called **user defined functions**.

A **function call** tells the CPU to interrupt the current function and execute another function. the cpu essentially puts a bookmark at the current point of the execution then returns to the point it bookmarked and resumes execution

Ex of user-defined function:

```cpp
returnType functionName() //function header
{
	//this is the function body
}
```

First line = function header. tells the executer about the existence of the function.

- in this lesson, we will use returnType of `int` (for function `main()` or `void`).
- Just like variables have names, so do **user-defined functions** the *functionName* is the name of your user-defined function.
- the  `()` parenthesis after the name tells the compiler that we are defining a function.

The curly braces and statements between are called the **function body**. This is where the statements that determine what your function does will go.

To use a function, we use the functions name followed by a parenthesis. `functionName()`.

For now, a function must be defined before it can be called.

EX:

```cpp
#include <iostream>

void doPrint()
{
	std::cout << "In doPrint()\n";
}

int main()
{
	std::cout << "Starting main()\n";
	doPrint();
	std::cout << "Ending main()\n";
	
	return 0
}

```

This program begins execution at the top of function `main()`, and the first line to be executed prints `Starting main()`.

The second line in `main()` is a function call to the function `doPrint()`. We know it’s a function call due to the trailing parentheses.

functions can be called more than once.

---
### Functions can call functions that call other functions.

Functions can call other functions see below ex:

```cpp
#include <iostream>

void doB()
{
	std::cout << "in doB\n";
}

void doA()
{
	std::cout << "in doA\n";
	doB();
	std::cout << "Ending doA\n";
}

int main()
{
	std::cout << "Starting main\n";
	doA();
	std::cout << "Ending main\n";
	
	return 0;
}

```

above, doB() was called from function doA() which was called within main().

---

### Nested functions are not supported

A function whos definition is placed inside another function is called a **nested function**. The following ex is not legal:

```cpp
#include <iostream>

int main()
{
    void foo() // Illegal: this function is nested inside function main()
    {
        std::cout << "foo!\n";
    }

    foo(); // function call to foo()

    return 0;
}
```

The proper way to write the above is:

```cpp
#include <iostream>

void foo()
{
	std::cout << "foo!\n";
}

int main()
{
	foo();
	
	return 0;
}
```
