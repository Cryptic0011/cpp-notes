**Whitespace** is a term that refers to chars that are used for formatting purposes. EX. spaces, tabs, and newlines. Its used for separating certain language elements, inside text, and for formatting code.

---

### Some language elements must be whitespace-seperated

Some elements must be seperated by whitespace. This mostly occurs when two keywords or identifiers must be placed consecutively, so the compiler can tell them apart.

`int x;`

if we typed `intx` it would treat it all as an identifier, and complain it doesnt know what intx means.

another ex:

`int main(); // int and main must be whitespace separated`

When whitespace is required, the compiler doesnt care how much whitespace is used, as long as it exists. All are valid

```cpp
int x;
int             x;
       int
x;
```

Quoted text will take the amount of whitespace literally.

```cpp
std::cout << "yo mama";
//is different than:
std::cout << "yo     mama";
```

Newlines are not allowed in quoted text:

```cpp
std::cout << "yo
mama"; //incorrect
```

## Basic formatting

c++ does not enforce formatting restrictions. some say c++ is a whitespace independent language.

Recommendations for basic formatting:

1. its fine to use tabs or spaces for indentation.
2. There are 2 styles for function braces.

Many devs prefer putting the opening brace on the same line as the statement like so:
```cpp
int main(){
	// statement here
}
```

Other devs (which i like more as its easier to read) put the opening brace on its own line
```cpp
int main()
{
	// statement here
}
```

3. Each statement within curly braces should start one tab in from the opening brace of the function it belongs to. EX:
```cpp
int main()
{
	std::cout << "yo mama"; // this line is tabbed in
}
```

4. lines should not be that long. typically 80 characters is standard. if its going to be longer, it should be split like so

```cpp
int main()
{
    std::cout << "This is a really, really, really, really, really, really, really, "
        "really long line\n"; // one extra indentation for continuation line

    std::cout << "This is another really, really, really, really, really, really, really, "
                 "really long line\n"; // text aligned with the previous line for continuation line

    std::cout << "This one is short\n";
}
```

5. if a line is split with an operator (like << or +) the operator should be placed at the beginning of the next line, not the end of the current line:

```cpp
std::cout << 3 + 4
    + 5 + 6
    * 7 * 8;
```


6. use whitespace to make your code easier to read by aligning values or comments:
   
```cpp
cost = 57;
pricePerItem = 24;
value = 5;
numberOfItems = 17;
```

vs
```cpp
cost          = 57;
pricePerItem  = 24;
value         = 5;
numberOfItems = 17;
```
