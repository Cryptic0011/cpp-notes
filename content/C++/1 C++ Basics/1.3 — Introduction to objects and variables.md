In programming, a single piece of `data` is called a value. Ex

- numbers 5, -6
- Characters, which are placed between single quotes(only a single symbol may be used)
- Text, placed between double quotes "Hello". Text can contain 0 or more characters

Values places directly in the source code are called `literals`

One of the most common thing to do with values is print them to the screen:

```cpp
#include <iostream>

int main()
{
	std::cout << 5; //print the literal number 5
	std::cout << -6.7; //print the literal number -6.7
	std::cout << 'H'; //print the literal character H
	std::cout << "Hello;" //print the literal text Hello
	
	return 0;
}
```

`literals` are read only values so their values cannot be modified.

## Random Access Memory

Main memory in a computer is called `RAM`. When we run a program, the os loads the program into RAM. Any data hardcoded in the program is loaded into RAM.

The OS reserves additional RAM for the program to use. while its running such as areas to store values entered by the user. 

---

##  Objects and variables

in c++ direct memory access is discouraged. Instead we access memory indirectly through an **object**. An `object` represents a region of storage that can hold a value.

This means we can focus on using objects to store and retrieve values.

- we name objects using an identifier. An object with a name is called a `variable`.

- an **object** is used to store a value in memory & a **value** is an **object** that has a name (identifier)


### Variable definition

 In order to use a variable, it needs to be declared in a `definition`.
Ex. of defining a **variable** named x:

```cpp
int x; // define a variable named x of type int
```

- For now our **variables** should be stored inside of functions, such as `main()`

```cpp
int main()
{
	int x; // definition of variable x
	return 0;
}	
```

### Variable Creation

At runtime, each object is given an action storage location that it can use to store the values. The process of reserving storage for an objects use is called an `allocation`.

Ex. variable x is in memory location 140. Whenever the program uses variable x, it will access the value in memory located in 140.

## Data Types

A `data type` or **type** determines what kind of value the object will store. 
Ex.  in our above example, our variable x was given type int, which means veriable x will store an integer value. an `integer` is a number that can be written without a fractional component like 4, 25, -2.

Another Ex. defining a variable with type **double**

```cpp
double width; //define variable named width of type double
```

### Defining multiple variables

it is possible to define multiple variables of the same type in a single statement by seperating the names with a comma.

```cpp
int a;
int b;
```

is the same as

```cpp
int a, b;
```

Ex. of a mistake

```cpp
int a, int b; //wrong
int a, b; //correct
```

Second type if mistake is trying to define variables of different types in the same statement
Ex.
```cpp
int a, double b; //wrong
int a; double b; // will work but not good practice

// correct and reccomended:
int a;
double b;
```
