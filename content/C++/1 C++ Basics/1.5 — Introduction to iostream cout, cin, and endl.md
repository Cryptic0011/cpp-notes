## The input/output library

The **input/output** library is part of the c++ standard lib that deals with basic input and output. also called **io library**.

The functionality is defined with the *iostream* library. this library needs to be in the header at the top of any code file that uses the content defined in iostream like so:

```cpp
#include <iostream>
```

---
## std::cout

**iostream** contains predefined variables for us to use. One of the most useful is **std::cout**, which allows us to send data to the console to be printed as text. cout stands for "character output".

```cpp
#include <iostream>

int main()
{
	std::cout << "Hello world;
	return 0;
}
```

above, we included iostream so that we could have access to std::cout. Inside our main function, we use std::cout, along with the insertion operator << to send the string to the console to be printed.

_std::cout_ can not only print text, it can also print numbers:

```cpp
#include <iostream>

int main()
{
	std::cout << 4; //print 4 to console
	return 0;
}
```

It can also be used to print the value of variables

```cpp
#include <iostream>

int main()
{
	int x{ 5 };
	std::cout x; //print value of x to console
	return 0;
}
```

to print more than one thing on a single line, use << multiple times in a single statement.

```cpp
std::cout << "hello" << " world";
```

Another example:

```cpp
#include <iostream>

int main()
{
	int x{5}
	std::cout << "x is equal to: " << x;
	return 0;
}
```

### using std::endl to output a new line
If we want to print seperate lines, we need to tell the console to move the cursor to the next line.
a **newline** is an OS specific character that moves the cursor to the start of the next line.

One way to output a new line is `std::endl` which stands for end line.

```cpp
#include <iostream>

int main()
{
	std::cout << "Hi!" << std::endl; //std::endl moves to the next line
	std::cout << "My name is Grayson." << std::endl;
	
	return 0
}
```

This prints
```
Hi!
My Name is Grayson.
```

### std::endl vs \n
std::endl is often inefficient, as it outputs a new line and flushes the buffer which is slow. If we output multiple lines of text ending with std::endl, we get multiple flushes.

to output a newline without flushing the output buffer, we use \n inside quotes which is a symbol that the compiler interprets as a new line. \n moves the cursor to the next line in the console without flushing.

```cpp
#include <iostream>
{
int main()
	int x{5};
	std::cout << "x is equal to: " << x << "\n";
	std::cout << "And thats all!\n"
	return 0;
}
```

## std::cin

**std::cin** is another variable defined in the iostream lib. Whereas std::cout prints data to the console, **std::cin** (character input) reads input from a keyboard. We typically use the extraction operator `>>` to put the input data in a variable, which can then be used in subsequent statements.

```cpp
#include <iostream>

int main()
{
	std::cout << "Enter a number: "; //asks user for a number
	
	int x{}; //define variable x to hold user input.
	std::cin >> x; //get a number from keyboard and store it in a variable
	
	std::cout << "You entered " << x << '\n'
	return 0;
}
	
```

Its possible to output more than one variable on a single line:

```cpp
#include <iostream>

int main()
{
	std::cout << "Enter a number seperated by a space: ";
	int x{};
	int y{};
	std:cin >> x >> " and" << y << '\n';
	
	std::cout << "you entered " << x << " and" << '\n';
	return 0;
}
```

or two stage process:

```cpp
#include <iostream>  // for std::cout and std::cin

int main()
{
    std::cout << "Enter two numbers: ";

    int x{};
    std::cin >> x;

    int y{};
    std::cin >> y;

    std::cout << "You entered " << x << " and " << y << '\n';

    return 0;
}
```

## Operator << vs Operator >>

- `std::cin` and `std::cout` always go on the left-hand side of the operator
- `std::cout` is used to output a value.
- `std::cin` is used to get an input value
- `<<` is used with `std::cout` and shows the direction the data is moving. `std::cout << 4` moves the value `4` to the console
- `>>` is used with `std::cin` and shows the direction the data os moving. `std::cin << x` moves the value entered by the user into variable x.

Question #2

Ask the user to enter three values. The program should then print these values. Add an appropriate comment above function `main()`.

The program should match the following output (when run with input values `4`, `5`, and `6`):

Enter three numbers: 4 5 6
You entered 4, 5, and 6.

My answer (which was correct:)

```cpp
#include <iostream>  

int main()
{
    std::cout << "Enter three numbers followed by spaces "; // ask user for a number
    int x{}, y{}, z{}; 
    std::cin >> x >> y >> z; 
    std::cout << "You entered " << x << ", " << y << ", " << " and "<< z << ".\n";

    return 0;
}
```
