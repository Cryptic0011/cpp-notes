
This lesson we will be putting values into **variables**

Ex. from last lesson, defining variables:
```cpp
into main()
	int x;

```

After a **variable** is defined, you can give it a value using the = operator. This process is called **assignment** and the = operator is called the **assignment operator**.
```cpp
int width;
width = 5; // assigning the value 5 into variable width
```

Once a variable has been given a value, it can be printed.

Assignment can be used whenever we want to change the value held be a **variable.** Ex:
```cpp
#include <iostream>

into main()
{
	int width;
	width = 5;
	
	std::cout << width; // prints 5
	
	width = 7;
	
	std::cout << width; //prints 7
	return 0;
}
```

This will print 
```
57
```

Normal **variables** can only hold one value at a time.

## Variable initialization

You can combine defining an object and giving it a value into one statement. This is called initialization.

Ex.
```cpp
#include <iostream>

int main()
	int width { 5 } // define variable and initialize with value 5
	std::cout << width; // prints 5
```

### Different forms of initialization

```cpp
int a;         // default-initialization (no initializer)

// Traditional initialization forms:
int b = 5;     // copy-initialization (initial value after equals sign)
int c ( 6 );   // direct-initialization (initial value in parenthesis)

// Modern initialization forms (preferred):
int d { 7 };   // direct-list-initialization (initial value in braces)
int e {};      // value-initialization (empty braces)
```


### Initializing multiple variables

```cpp
int a = 5, b = 6; // copy initialization
int c (7), d (8); // direct-initialization
int e {9}, f {10}; // direct-list-initialization
int i {}, j {}; // value initialization
```

Value initialization sets value to 0, or whatever is closest to 0. for example 
```cpp
bool active {};
```
 initializes false to `active`

Example of initializing in real code:

