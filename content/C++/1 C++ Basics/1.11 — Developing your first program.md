
This lesson included a quiz, requested to produce the following: 

`Enter an integer: 4`
`Double 4 is: 8`
`Triple 4 is: 12`

My answer: 

```cpp
#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";
    
    int num{};
    std::cin >> num;
    
    std::cout << "Double " << num << " is: " << 2 * num << '\n';
    std::cout << "Triple " << num << " is: " << 3 * num << '\n';
    
    return 0;
}
```
