## Identifier naming rules

The name if a variable is called an identifier. There are a few rules when naming them:

1. it cannot be a keyword (listed above)
2. it can only be composed of letters, numbers, and the underscore character.
3. it must begin with a letter or underscore, not a number.
4. it is case sensitive ex. `nvalue`, `nValue` and `NVALUE` would all be different

### Identifier best naming practices
How should we name them?
1. should begin with a lowercase letter. if it is a single word, the whole thing should be written in lowercase letters. `int value;` 

	Identifier names that start with a capital letter are typically used for user-defined types like structs classes and enumerations.
	If the var or function is multiword, you can do lowercase words seperated by underscores or intercapped 

```cpp
int my_variable_name;   // conventional (separated by underscores/snake_case)
int my_function_name(); // conventional (separated by underscores/snake_case)

int myVariableName;     // conventional (intercapped/camelCase)
int myFunctionName();   // conventional (intercapped/camelCase)
```

Intercapped is easier to read.

2. Avoid naming your identifiers. starting with an underscore. these names are usually reserved for os, library, or compiler use.
3. names of identifiers should make clear what the value they are holding means.
4. avoid abbreviations, except when they are common like `num, cm, idx`
