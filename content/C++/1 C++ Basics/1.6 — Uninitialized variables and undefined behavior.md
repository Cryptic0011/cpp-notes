
## Uninitialized variables

c++ does not automatically init most variables to a given value (such as 0). When a variable that is not initialized is given a memory address to use to store data, the default value of that var is whatever garbgae value happens to already be in that memory address! A variable that has not been given a known value is called an **uninitialized variable**.

- Initialized = The object is given a known value at the point of definition.
- Assignment = The object is given a known value beyond the point of definition.
- Uninitialized = The object has not been given a known value yet.

ex:
`int x;`

## Undefined Behavior

Using the value from an uninitialized variable is our first example of undefined behavior. 

## Implementatoin defined behavior and unspecified behavior

A specific compiler and the associated standard library it comes with are called an implementation. 

Behavior that is defined by the implementation is called **implementation-defined behavior**.

simple ex. of implementation-defined behavior:

```cpp
#include <iostream>

int main()
{
	std::cout << sizeof(int) << '\n'; // print how many bytes of memory an int val takes
	return 0;
}
```

This will return different value depending on the machine
