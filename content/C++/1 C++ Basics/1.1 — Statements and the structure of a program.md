A `Statement` is a type of instruction that causes the program to perform an action
	In cpp, when we want to have our program do something, we typically will write a statement.
	Most statements end with a semicolon;

A `Function` is a collection of statements that get executed in order from top to bottom.

* Every cpp program must have a special function named main

when a program is run, the statements inside of `main` are executed in sequential order. Programs will typically close after the last statement in main has been executed.

Functions are typically written to do a specific job or perform some useful action. For example, a function named `max` might contain statements that figures out which of two numbers is larger. A function named `calculateGrade` might calculate a student’s grade from a set of test scores. A function named `printEmployee` might print an employee’s information to the console.

Function names are followed by parentheses. EX. function main is main()
The name of a function is called its `identifier`

### Characters & Text

A **character** is a written symbol or mark, such as a letter, digit, punctuation mark, or mathematical symbol EX. a, 2, $, =

A sequence of characters is called a `text` or a `string`

Its also meant to mean plain text (only characters that appear on a keyboard)

### Syntax & syntax errors

In english, sentences are constructed with grammatical rules. The set of rules that describe how specific words can be arranged to form valid sentences in a language is called syntax.

c++ has syntax which describes how the elements of your program must be written and arranged in order for the program to be considered valid. When you build, your compiler makes sure your program follows the syntactical rules.

- syntax rules are strict
