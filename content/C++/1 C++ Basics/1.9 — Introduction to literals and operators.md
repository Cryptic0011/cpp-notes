## Literals
consider the following statements

```cpp
	std::cout << "yo mama";
	int x { 5 };
```
yo mama and 5 are literals. a **literal** is a fixed value that has been inserted directly into the code.

variables can be changed while the value of a literal is fixed and cannot be changed. the **literal** 5 always has the value 5. This is why **literals** are called constants.

To further identify literals and variables:
```cpp
#include <iostream>

int main()
{
	std::cout << 5 << '\n'; // print value of literal
	
	int x{5};
	std::cout << x << '\n'; // print value of variable
	return 0;
}
```

in the first std::cout, 5 can be printed directly as a literal and on the second std::cout 5 must be fetched from memory to represent the variable.

## Operators

An **operation** is a process involving zero or more input values called **operands** that produce a new value(called an output value). The specific operation to be performed is denoted by a symbol called an **operator**.

2+3, in this example 2 & three are the operands and the symbol + is the operator that tells us to apply the mathmatical equation. EX:
```cpp
int main()
{
    std::cout << 1 + 2 << '\n';

    return 0;
}
```
above, 1 & 2 are the operands to the + operator which produces the output of 3. the output value is to be printed to the console, and is called a **return value**.

EX operators `+, -, *, /, =, <<, >>, and == (equality)`
some number operators also have keywords: `new, delete, throw`

the number of operands an operator takes as input is called the operators **arity**.
	**Unary**: operators act on one operand. 
	**Binary:** opers act on two opperands. 3+4.
	**Ternary** operators act on three operands.
	**Nullary**: operators act on zero operands.

## Chaining operators

Operators can be chained together, so that the output of one operator can be used as the input for another operator. ex. 2 * 3 + 4. The multiplication operator goes first converting into 6 which becomes the left hand operand for the + operator for + 4.

the order in which operators execute is the same as PEMDAS.

## Return values and side effects

An operator that has some observable effect beyond producing a return value is said to have a **side effect**. Ex. `x = 5` has the side effect of assigning valule 5 to variable x. `std::cout << 5` has the side effect of printing 5 to the console.
